函数声明与调用

⭐ Go 中函数通过 func 关键字声明，基本语法：func 函数名(参数列表) 返回值类型

💡 当多个参数类型相同时，可以简写：func add(a, b int) int，只在末尾写一次类型。

参数传递机制

🧠 Go 中所有参数传递都是值传递（pass by value），没有引用传递。

但根据参数类型的不同，效果有区别：

参数类型 传递的内容 修改底层数据是否影响调用方
基本类型（int、string、bool 等） 值的副本 ❌ 不影响
引用类型（slice、map、channel、指针等） 引用（指针）的副本 ✅ 影响（指向同一块底层数据）

⚠️ 注意：引用类型传递的是引用的副本。通过它修改底层数据可见，但如果在函数内重新赋值这个引用本身（指向新对象），调用方不可见。

多返回值

⭐ Go 支持函数返回多个值，用括号包裹多个返回值类型。

💡 多返回值是 Go 的特色，常用于返回「结果 + 错误」模式：func foo() (result, error)

命名返回值

⭐ 命名返回值就是在返回值类型前给返回值起一个名字，在函数体内可以直接使用该变量。

特性 说明
命名返回值 在返回值类型前加变量名，如 (res int)
默认值 命名返回值变量自动初始化为零值
裸 return 函数体末尾直接 return，无需指定返回值，自动返回命名变量

⚠️ 命名返回值在函数体较短时方便，但在长函数中使用裸 return 可能降低可读性（不易看出返回了什么）。

函数作为变量（匿名函数）

⭐ 在 Go 中，函数是一等公民（first-class citizen）：可以赋值给变量、作为参数传递、作为返回值返回。

1. 赋值给变量

2. 短变量声明 + 匿名函数

💡 匿名函数没有函数名，通过 func(参数) 返回值 { 函数体 } 定义，常用于赋值给变量或立即调用（IIFE）。

总结与速记

1. 函数核心知识点

维度 说明
声明语法 func 函数名(参数列表) 返回值类型
参数简写 同类型参数可合并：func f(a, b int)
传递机制 始终值传递；基本类型拷贝值，引用类型拷贝引用（指向同一底层数据）
多返回值 (int, int) 括号包裹多个返回值类型
命名返回值 (res int)，自动初始化零值，支持裸 return
一等公民 函数可赋值给变量、作为参数 / 返回值传递
匿名函数 func(参数) 返回值 { 函数体 }，无函数名

2. 易错点提醒

❌ Go 没有引用传递，只有值传递。引用类型传参传递的是引用的副本，修改底层数据可见，但重新赋值引用本身不可见。

❌ 命名返回值的裸 return 会自动返回命名变量，不要在长函数中滥用以免降低可读性。

❌ var x func() 声明后 x 是 nil，不能直接调用（会 panic），必须先赋值。
