for 基本语法

⭐ Go 中只有 for 一个循环关键字，没有 while、do-while。所有循环都用 for 实现。

💡 语法与 C/Java 类似：for 初始化; 条件; 后置 { }，但 Go 的 for 后面没有括号，必须有大括号。

for range 遍历

⭐ for range 用于遍历切片、数组、字符串、Map、Channel。

1. 遍历切片 / 数组

⚠️ for i := range s 中 i 是 index（索引），不是 value。

2. 遍历字符串（按 rune）

🧠 range 遍历字符串时，按 rune（Unicode 码点） 而非字节遍历。i 是 byte offset（字节偏移），不是字符序号。一个中文字符占 3 个字节，所以”语”的 offset 是 2，”言”的 offset 是 5。

3. 遍历 Map

⚠️ Map 遍历的顺序是随机的，每次运行结果可能不同。如果需要有序遍历，需先对 key 排序。

4. 遍历 Channel

💡 range 遍历 Channel 会持续接收值，直到 Channel 被 close 关闭。

与 Java 对比

⭐ Go 用一个 for 关键字覆盖了 Java 中三种循环结构。

功能 Java Go 说明
标准 for for (int i = 0; i < n; i++) for i := 0; i < n; i++ 语法几乎一致，Go 无括号
while while (cond) { } for cond { } Go 无 while 关键字
do-while do { } while (cond); for { ...; if !cond { break } } Go 无 do-while，需手动模拟
增强 for for (int x : arr) for i, v := range arr Go 的 range 同时给索引和值
无限循环 while (true) { } for { } Go 更简洁
循环关键字数量 3 个（for、while、do） 1 个（for） Go 更统一

3. 易错点提醒

❌ for i := range s 中 i 是索引，不是值。要取值需 for _, v := range s。

❌ range 遍历字符串时，i 是 byte offset 而非字符序号，中文字符占 3 字节。

❌ Map 的 range 遍历顺序是随机的，不要依赖遍历顺序。

❌ Go 1.22 之前循环变量被闭包/协程捕获时会出错，需手动传参。
