方法：给结构体附加行为

⭐ Go 的方法通过接收者（Receiver） 绑定到结构体上，格式为 func (接收者) 方法名(参数) 返回值。

1. 值接收者 vs 指针接收者

接收者类型 语法 能否修改原对象 说明
值接收者 func (p Person) ... ❌ 操作的是副本 适合只读方法
指针接收者 func (p *Person) ... ✅ 操作的是原对象 适合修改方法

⚠️ 一致性原则：如果一个结构体有指针接收者的方法，建议所有方法都用指针接收者，保持一致。

💡 Go 会自动取地址 / 解引用，所以 p.SetAge(25) 和 (&p).SetAge(25) 都可以编译通过。

2. 与 Java 方法的对比

差异 Java Go
方法定义位置 class 内部 struct 外部
自身引用 this 关键字 接收者变量（自定义名称，如 p）
接收者类型 隐式（this 是引用） 显式选择值或指针

封装：通过可见性控制

⭐ Go 没有 public / private / protected 关键字，通过首字母大小写控制可见性。

首字母 可见性 等价
大写 导出（exported），包外可见 public
小写 未导出（unexported），仅包内可见 private

🧠 Go 没有继承，所以也不需要 protected（包内可见 + 子类可见）。

组合优于继承

⭐ Go 没有 extends，没有继承，没有 super。Go 的哲学是组合优于继承，通过结构体嵌入实现代码复用。

3. 方法遮蔽（Shadowing）≠ 方法重写（Override）

⚠️ 遮蔽 ≠ 重写。Go 没有多态/虚方法表，方法的调用取决于编译期类型，而非运行时类型。

特性 Java Go
定义”类” class Person { ... } type Person struct { ... }
创建对象 new Person(...) Person{Name: ...} 或 NewPerson(...)
构造函数 与类同名的方法 ❌ 无，用工厂函数 NewXxx
自身引用 this 接收者变量（自定义名称）
方法定义 class 内部 struct 外部 + 接收者
封装 public / private / protected 首字母大写导出 / 小写未导出
继承 extends（单继承） ❌ 无继承

核心差异总结

⭐ Go 的设计哲学：将继承的复杂性留给接口，将代码复用的能力留给组合。

总结与速记

1. 核心知识点

维度 说明
类 结构体 struct 替代 class
方法 接收者绑定，值接收者（只读）/ 指针接收者（可修改）
封装 首字母大写 = 导出，小写 = 未导出，无 protected
构造函数 无，用 NewXxx 工厂函数替代
继承 ❌ 无继承，用结构体嵌入（组合）替代
方法提升 嵌入结构体的字段和方法被提升到外层
遮蔽 外层定义同名方法会遮蔽嵌入方法（≠ 重写）
多态 仅通过接口实现，结构体嵌入无多态
多重组合 支持嵌入多个结构体（对比 Java 单继承）

3. 易错点提醒

❌ Go 没有继承，结构体嵌入是组合（has-a），不是 is-a。

❌ 方法遮蔽（Shadowing）≠ Java 的方法重写（Override）。Go 没有虚方法表，嵌入方法调用是静态分发的。

❌ Go 没有 this 和 super，访问嵌入结构体的被遮蔽方法需显式写出：d.Animal.Eat()。

❌ 指针接收者方法修改的是原对象，值接收者方法操作的是副本。如果方法需要修改对象，必须用指针接收者。

❌ 未导出字段（小写开头）在包外不可直接访问，需通过工厂函数或导出方法设置。
