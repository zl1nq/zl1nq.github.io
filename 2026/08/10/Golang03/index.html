Map 基础

⭐ Map（映射） = 键值对（key-value）类型，通过 key 快速查找对应的 value。

1. 声明与初始化

⚠️ 重要：var m map[string]int 仅声明后 m 是 nil，不能直接写入（会 panic），必须用 make 初始化后才能赋值。

2. 访问不存在的 key

💡 访问不存在的 key 不会报错，而是返回 value 对应类型的零值（int 类型就是 0）。

创建 Map 的三种方式

方式 语法 说明
make make(map[K]V) 最常用，创建空 map
make + 容量 make(map[K]V, cap) 可预分配容量（可选）
字面量 map[K]V{...} 声明时直接初始化键值对

⚠️ 易错：使用字面量初始化 map 时，最后一个元素的逗号不能省略，否则编译报错。

判断 key 是否存在

🧠 由于访问不存在的 key 只返回零值（不报错），无法区分「key 存在且值为 0」和「key 不存在」。因此 Go 提供了 comma-ok 模式。

返回值 含义
value key 对应的值（不存在则为零值）
ok true 表示 key 存在，false 表示不存在

💡 这就是 Go 中经典的 comma-ok（逗号 ok）模式，在类型断言、通道接收等场景也会用到。

删除元素

使用内置函数 delete 删除指定 key：

💡 delete(map, key) 删除指定 key。如果 key 不存在，不会报错，也没有任何副作用。

Map 是引用类型

⭐ 关键特性：Map 是引用类型，赋值时共享底层数据，修改会相互影响。

❌ Map 和切片一样是引用类型，赋值 / 传参不会复制数据，而是共享底层哈希表。修改一个会影响另一个。

总结与速记

1. Map 核心知识点

维度 说明
本质 键值对（key-value）映射，通过 key 快速查找 value
声明 var m map[K]V（声明后是 nil，需 make 初始化才能写入）
初始化 make(map[K]V) 或字面量 map[K]V{...}
引用类型 赋值 / 传参共享底层数据，修改相互影响
零值访问 不存在的 key 返回零值，不报错
判断存在 comma-ok 模式：value, ok := m[key]
删除 delete(m, key)，key 不存在也不报错

2. 易错点提醒

❌ var m map[string]int 声明后是 nil，必须 make 初始化才能写入，否则 panic。

❌ 字面量初始化时最后一个元素的逗号不能省略。

❌ 访问不存在的 key 返回零值而非报错，需用 comma-ok 模式区分「值为零值」和「key 不存在」。

❌ Map 是引用类型，赋值 / 传参共享底层数据，修改会相互影响。
