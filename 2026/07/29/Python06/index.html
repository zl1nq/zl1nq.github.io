一、什么是魔法方法

⭐ 核心特征：魔法方法是那些以双下划线开头和结尾的特殊方法，例如 __init__、__str__。
不需要手动调用——当使用某些内置操作（如 print()、len()、+ 运算符、for 循环等）时，Python 解释器会在后台自动触发它们。

魔法方法的作用：让自定义类无缝融入 Python 的原生语法，让你的对象表现得像内置的列表、字典或数字一样自然。

你写的代码 Python 自动调用
obj = MyClass() obj.__new__() → obj.__init__()
print(obj) / str(obj) obj.__str__()
len(obj) obj.__len__()
obj[key] obj.__getitem__(key)
a + b a.__add__(b)
for x in obj obj.__iter__() → __next__()

💡 类比 Java：类似 toString()、equals()、Comparable 接口等，但 Python 的魔法方法更丰富，支持运算符重载。

二、对象生命周期（创建 / 初始化 / 销毁）

对应对象从创建到销毁的整个生命周期。

1. __new__(cls, ...) — 真正的「构造器」

项目 说明
作用 负责创建并返回一个实例对象（在内存中分配空间）
执行时机 在 __init__ 之前执行
第一个参数 cls（类本身），不是 self
日常使用 业务代码极少重写，单例模式等特殊场景才用

2. __init__(self, ...) — 初始化器 ⭐

项目 说明
作用 负责「初始化」，给创建好的对象设置初始属性
执行时机 在 __new__ 之后执行
第一个参数 self（刚创建好的实例）
日常使用 最常用，几乎每个类都写

3. __del__(self) — 析构函数

项目 说明
作用 对象即将被垃圾回收时触发
典型用途 清理资源（关闭文件、断开连接）
注意 触发时机不确定，不推荐依赖它做资源清理——优先用 with 上下文管理器

💡 三者顺序：__new__（创建对象）→ __init__（初始化属性）→ 使用对象 → __del__（对象销毁）

三、字符串表示（让对象「会说话」）

两个魔法方法，让对象在被打印时能输出有意义的信息，而不是默认的 <__main__.P object at 0x...>。

1. __str__(self) — 面向用户

项目 说明
触发时机 print(obj) 或 str(obj)
目标读者 面向最终用户，返回友好、易读的字符串

2. __repr__(self) — 面向开发者

项目 说明
触发时机 交互式解释器输入对象名，或 repr(obj)
目标读者 面向开发者，调试用
理想状态 eval(repr(obj)) 能重新生成该对象

__str__ vs __repr__ 对比

方法 触发场景 面向对象 返回风格
__str__ print / str 终端用户 友好易读
__repr__ 交互模式 / repr 开发者 精确、可重建对象

💡 最佳实践：如果只写一个，优先写 __repr__。当 __str__ 未定义时，Python 会 fallback 到 __repr__。

四、容器与迭代协议（让对象像列表/字典）

实现这些魔法方法后，你的自定义类就能像列表/字典一样，支持 len()、索引、切片、for 循环等操作。

1. __len__(self) — 支持 len(obj)

2. __getitem__(self, key) — 支持 obj[key] 取值

场景 效果
obj[2] 触发 __getitem__(self, 2)
obj["name"] 触发 __getitem__(self, "name")
obj[1:5]（切片） 触发 __getitem__(self, slice(1, 5, None))

3. __setitem__(self, key, value) — 支持 obj[key] = value 赋值

4. __delitem__(self, key) — 支持 del obj[key] 删除

5. __iter__(self) + __next__(self) — 支持 for 循环 ⭐

  • __iter__()：返回迭代器对象（通常返回 self）
  • __next__()：每次返回下一个元素，没有元素时抛 StopIteration 异常

这两个方法实现后，就能用 for item in obj: 遍历你的对象。

五、运算符重载（让对象支持加减乘除）

Python 允许自定义类的对象使用运算符（+, -, *, ==, < 等），其实质就是调用对应的魔法方法。

1. 算术运算符

运算符 魔法方法 说明
a + b __add__(self, other) 加法
a - b __sub__(self, other) 减法
a * b __mul__(self, other) 乘法
a / b __truediv__(self, other) 除法（Python 3）

2. 比较运算符 ⭐

运算符 魔法方法 说明
a == b __eq__(self, other) 相等判断
a != b __ne__(self, other) 不相等（未定义时自动用 not __eq__）
a < b __lt__(self, other) 小于
a <= b __le__(self, other) 小于等于
a > b __gt__(self, other) 大于
a >= b __ge__(self, other) 大于等于

💡 偷懒技巧：配合 @functools.total_ordering 装饰器，只要定义 __eq__ + 任意一个比较方法（如 __lt__），其余 4 个比较方法会自动补全！

七、魔法方法速查表

1. 生命周期

魔法方法 触发时机
__new__(cls) 创建实例（极少重写）
__init__(self) 初始化实例属性
__del__(self) 实例被垃圾回收

2. 字符串表示

魔法方法 触发时机
__str__(self) print() / str()，面向用户
__repr__(self) repr() / 交互模式，面向开发者

3. 容器与迭代

魔法方法 触发时机
__len__(self) len(obj)
__getitem__(self, key) obj[key] 取值 / 切片
__setitem__(self, key, val) obj[key] = val 赋值
__delitem__(self, key) del obj[key] 删除
__iter__(self) iter(obj) / for 循环开始
__next__(self) 迭代器取下一个值
__contains__(self, val) val in obj 成员判断

4. 运算符重载（常用）

类别 魔法方法 对应运算符
算术 __add__ / __sub__ / __mul__ / __truediv__ + - * /
比较 __eq__ / __ne__ / __lt__ / __le__ / __gt__ / __ge__ == != < <= > >=
位运算 __and__ / __or__ / __xor__ & | ^

5. 可调用对象

魔法方法 触发时机 说明
__call__(self, *args) obj(args) 让实例可以像函数一样被调用

💡 __call__ 的妙用：装饰器类（用类实现装饰器）、把复杂逻辑封装成可调用对象。

八、总结与速记

魔法方法学习建议

  1. 优先掌握高频 6 个：__init__、__str__、__repr__、__len__、__eq__、__add__
  2. 理解核心思想：魔法方法 = **让自定义类对接 Python 原生语法糖
  3. 配合标准库：@total_ordering 省一半比较代码
