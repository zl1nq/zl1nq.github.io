一、核心概念（类比 Java）

⭐ 一句话理解：装饰器 = 注解 + AOP 的 Python 实现，但比 Java 注解更强大——它是运行时动态修改函数行为，而 Java 注解多数时候只是「标记」。

类比 Java

概念 Java Python 装饰器
典型例子 @Override, @Transactional @login_required, @timer
本质 编译期元数据（标记） 运行时包装函数，真正执行逻辑
AOP 实现 Spring AOP（动态代理） 装饰器天然就是 AOP，无需框架

定义

本质：装饰器是一个接收函数、返回新函数的高阶函数。
在不修改原函数代码的前提下，为原函数动态添加额外功能（日志、鉴权、计时、缓存等）。

2. 执行过程详解（为什么是三层？）

当写下 @log_level("INFO") 时，Python 分两步执行：

步骤 过程 说明
第一步 先执行 log_level("INFO") 传参给第 1 层，返回第 2 层 decorator；同时 level="INFO" 被闭包记住
第二步 再执行 @decorator 等价于 @decorator，把 do_something 传给 decorator，返回 wrapper

调用 do_something() 时，实际调用的是最内层的 wrapper，它会先打印记住的 level，再调用原函数。

🧠 三层嵌套职责分明：

  • 第 1 层：专门接收装饰器的配置参数
  • 第 2 层：专门接收被装饰的函数
  • 第 3 层：专门接收原函数的参数，执行附加逻辑

六、语言级内置装饰器

这些装饰器是 Python 语言内置的，无需导入。

1. @staticmethod

作用：定义静态方法。把函数绑定到类上，但不需要访问 self（实例）或 cls（类）。
本质上就是放在类命名空间里的普通函数。

适用场景：逻辑上属于这个类，但不需要依赖类的任何状态（工具函数）。

2. @classmethod

作用：定义类方法。第一个参数自动接收类本身（约定命名为 cls），而不是实例 self。

适用场景：

  • 工厂方法（通过不同方式创建实例）
  • 操作类级别的变量（类变量）

3. @property

作用：将方法「伪装」成属性。用 obj.attr 的方式调用，而不是 obj.attr()。
通常配合 @attr.setter 和 @attr.deleter 使用。

适用场景：获取/设置属性时加入逻辑（类型检查、计算属性），同时保持 API 简洁。

💡 详细示例见 Python04.md：类与对象 中的对应章节。

七、标准库常用装饰器

这些来自 Python 标准库，需要 import 后使用。

1. @functools.wraps(func)

项目 说明
作用 保留被装饰函数的原始名称和文档字符串（__name__, __doc__）
场景 写任何自定义装饰器都建议用

2. @functools.lru_cache(maxsize=128) ⭐

项目 说明
作用 自动缓存函数的返回值。下次相同参数调用直接返回缓存，不再执行函数体
典型场景 递归计算（斐波那契数列）、频繁的网络请求、耗时的数据库查询

3. @functools.total_ordering

项目 说明
作用 只要定义了 __eq__ 和 一个比较方法（如 __lt__），自动补全其余比较（__le__, __gt__, __ge__）
场景 自定义类的对象需要排序或比较时，少写很多样板代码

4. @contextlib.contextmanager

项目 说明
作用 用生成器（yield）的方式编写上下文管理器，不需要写类实现 __enter__ / __exit__
场景 快速实现自定义的 with 语句（如自动管理数据库事务、临时切换工作目录）
