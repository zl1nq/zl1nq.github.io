一、列表 List

特点：有序、可变、可重复

列表是最常用的容器，相当于其他语言中的动态数组。

基本特性

  • 有序：元素有顺序，可以通过索引访问
  • 可变：可以随时增删改元素
  • 可重复：允许存储重复元素
  • 混合类型：可以混合存储不同类型的数据

二、元组 Tuple

特点：有序、不可变、可重复

元组可以看作是「只读的列表」。

基本特性

  • 有序：元素有顺序，支持索引
  • 不可变：一旦创建，不可修改（不能增删改）
  • 可重复：允许重复元素

基本语法

常用操作

操作 说明
索引与切片 同列表，只读访问
解包（Unpacking） a, b, c = my_tuple

适用场景

  • 存储不应被修改的固定数据（如坐标点 (x, y)、数据库查询返回的一行记录）
  • 作为字典的键（列表不能作为键，但元组可以，因为不可变）

三、集合 Set

特点：无序、可变、不可重复

集合在数学上代表一组不重复的元素，在 Python 中基于哈希表实现。

基本特性

  • 无序：元素不按插入顺序排列，不支持索引
  • 自动去重：重复元素自动合并为一个
  • 元素要求：元素必须是不可变类型（如数字、字符串、元组），不能是列表或字典

四、字典 Dict

特点：键值对、键不可重复、Python 3.7+ 保持插入顺序

字典是 Python 中最强大的内置数据结构之一，用于存储映射关系。

基本特性

  • 键值对存储：以 key: value 的形式存储数据
  • 键必须唯一：键不能重复，后面的值会覆盖前面的
  • 键不可变：键必须是不可变类型（通常是字符串、数字或元组）
  • 值任意：值可以是任意类型
  • 有序性：Python 3.7 及以上版本保持插入顺序

常用操作

访问与修改

操作 说明
my_dict["key"] 获取值，键不存在则报错
my_dict.get("key", default) 获取值，键不存在返回默认值（推荐）
my_dict["new_key"] = value 添加或修改键值对
setdefault(key, default) 键存在返回值，否则添加并返回默认值

遍历

方法 说明
keys() 获取所有键
values() 获取所有值
items() 获取所有键值对（元组形式）

删除

方法 说明
pop("key") 删除并返回指定键的值，键不存在则报错
pop("key", default) 删除并返回，不存在返回默认值
popitem() 删除并返回最后一个键值对（3.7+ 按插入顺序）
clear() 删除所有元素
del my_dict["key"] 删除指定键值对

其他

方法 说明

fromkeys(keys, value) 创建新字典，所有键为 keys，值都为 value
