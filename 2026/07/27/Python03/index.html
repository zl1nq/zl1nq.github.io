一、函数基础

核心概念：函数是组织好的、可重复使用的代码块，用于执行单一或相关联的任务。

1. 函数的定义与调用

  • 定义：使用 def 关键字，后跟函数名、括号（包含参数）和冒号，函数体缩进
  • 调用：通过 函数名(实参) 的形式执行
  • 规则：函数必须先定义后调用，否则报 NameError

2. 返回值 return

  • 使用 return 语句将结果返回给调用者
  • 没有 return 或 return 后无数据，函数默认返回 None
  • return 会立即终止函数执行

二、形参与实参

术语 全称 说明
形参 形式参数 函数定义时括号内的变量名，相当于占位符，调用时才分配内存
实参 实际参数 函数调用时传入的具体数据值，可以是常量、变量或表达式

三、参数传递机制：按对象传递

⭐ 核心结论：Python 的参数传递既不是纯粹的按值传递，也不是纯粹的按引用传递，而是按对象传递（传对象引用）。

具体表现取决于传入对象的类型。

1. 两种对象类型的差异

对象类型 例子 函数内重新赋值 函数内原地修改
不可变对象 int, str, tuple, float, bool ✅ 不影响外部 ——（不可变，无法原地改）
可变对象 list, dict, set ✅ 不影响外部 ❌ 会影响外部

2. 不可变对象：表现为「按值传递」

函数内部对参数重新赋值，不会影响外部原始对象——因为实际上创建了一个新的局部对象。

3. 可变对象：表现为「按引用传递」

函数内部对参数进行原地修改（如 append、update），会直接影响外部的原始对象。

四、五种参数类型详解

Python 提供了极其灵活的参数传递方式：

1. 位置参数

调用时实参与形参必须按从左到右的顺序一一对应，且数量一致。

2. 关键字参数

调用时使用 参数名=值 的形式，可以打破位置限制，代码可读性更强。

✅ 位置参数和关键字参数可以混用，但位置参数必须在前面。

3. 默认参数

定义时为形参赋予默认值。调用时若不传该参数，则使用默认值。

⚠️ 注意：默认参数必须放在普通位置参数的后面。

4. 动态位置参数：*args

接收任意数量的位置参数，并在函数内部将其打包为一个元组（tuple）。

💡 args 只是约定俗成的名字，你可以叫任何名字，但建议保持 args。

5. 动态关键字参数：**kwargs

接收任意数量的关键字参数，并在函数内部将其打包为一个字典（dict）。

六、经典陷阱：默认参数的可变对象 ⚠️

🔥 高频面试坑：默认参数是可变对象时会出问题！

1. 问题描述

在定义函数时，如果默认参数是可变对象（如列表 []），该对象在函数定义时只会被初始化一次。

后续所有未传入该参数的函数调用，都会共享同一个列表对象，从而导致数据污染。

💡 最佳实践：默认参数永远用不可变类型（None, 0, “” 等），不要用列表、字典等可变对象。
