一、with 上下文管理

⭐ 核心作用：确保代码块执行完毕后，自动执行清理/收尾工作，即使发生异常也一定会执行。

最常见的用途就是自动关闭文件，避免忘记写 f.close() 导致资源泄漏。

在 Python 中，with 关键字用于实现上下文管理（Context Management）。

  • 自动管理资源，无需手动 close
  • 异常安全：即使代码块内报错，资源也会被正确释放
  • 代码更简洁、可读性更高

二、文件打开模式

模式 说明 文件不存在时
'r' 只读模式（默认） 报错 FileNotFoundError
'w' 写入模式（会清空原文件内容） 自动创建新文件
'a' 追加模式（在文件末尾写入，不覆盖） 自动创建新文件
'x' 独占创建模式（仅当文件不存在时创建并写入） 自动创建新文件
'b' 二进制模式（常与 r/w/a 组合，如 rb, wb） -
't' 文本模式（默认，常与 r/w/a 组合，如 rt） -

⚠️ 注意：

  • w 模式会直接清空原文件内容，慎用！
  • 文本文件读写建议指定 encoding="utf-8"，避免乱码
  • 二进制模式（b）不能指定 encoding

七、拷贝 / 移动 / 删除

需要使用 shutil 模块。

操作 函数 注意事项
拷贝文件 shutil.copy() 目标是目录则拷贝到目录下
移动/重命名 shutil.move() 既可移动也可重命名
删除文件 os.remove() 只能删文件，不能删目录
删除空目录 os.rmdir() 目录非空会报错
递归删除目录 shutil.rmtree() ⚠️ 直接删除，不进回收站，慎用！

八、常见问题与总结

1. 为什么我的文件读写乱码？

  • 读写时没有指定 encoding="utf-8"，用了系统默认编码
  • 读写编码不一致（写用 gbk，读用 utf-8）

✅ 最佳实践：所有文本文件操作都显式指定 encoding="utf-8"。

2. with 语句只能用在文件操作吗？

不是。任何实现了上下文管理器协议（__enter__ 和 __exit__ 方法）的对象都可以用 with。

常见的有：

  • 文件操作：open()
  • 线程锁：threading.Lock()
  • 数据库连接
  • 临时文件：tempfile

3. read / readline / readlines 区别

方法 返回类型 说明
read() str 一次性读全部内容
readline() str 读一行
readlines() list 读所有行，返回列表

4. 速记总结

  • 读文件优先：for line in f: 逐行读，内存友好
  • 写文件注意：w 清空、a 追加，别搞混
  • 路径操作：优先用 pathlib.Path，现代优雅
  • 删目录小心：shutil.rmtree() 不可逆，慎用
  • 编码问题：永远指定 encoding="utf-8"
