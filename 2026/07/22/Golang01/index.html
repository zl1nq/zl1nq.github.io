变量的声明方式

全局变量 & 局部变量

1. 全局变量

声明位置：函数外面（包级别）

作用域：整个包内可用；首字母大写则包外其他包也能访问（导出变量）

特性：

  • 初始化时机：程序启动，main 执行之前完成初始化
  • 允许只声明不使用：编译不会报错（和局部变量最大区别）
  • 内存分配：堆/栈由编译器优化，不一定都在堆
  • 不可以使用短声明：:= 不能定义全局变量
  • 可以集中批量声明

2. 局部变量

声明位置：函数内部、代码块内部（for、if、{} 内部）

作用域：仅当前代码块有效

关键规则：

  • Go 不允许声明局部变量但不使用，直接编译报错
  • := 短变量声明不能在全局使用，只能局部
  • 生命周期：代码块执行完毕，变量失效

就近原则：当局部变量和全局变量同名时，优先使用局部变量，全局变量被屏蔽

常量

iota

1. 基础概念

iota 是 Go 预定义标识符，只能用在 const 常量声明块中。

  • 初始值为 0
  • 每新增一行常量声明，iota 自动 +1
  • 遇到新的 const 块，iota 重置为 0

本质：用来批量生成自增常量，常用来实现枚举。

数据类型

1. 布尔类型

本质：只有 true 和 false 两个值，分别表示真和假。

2. 整数类型

Go 语言中整数类型有 int、int8、int16、int32、int64 等，后面跟着的数字表示位数，默认位数会因为平台而不同。

注意：位数不同的变量之间不能直接转换，需要使用类型转换函数（强类型转换）。

3. 浮点数类型

Go 语言中浮点数类型有 float32、float64 等。

4. 字符和字符串

字符类型

Go 没有单独的 char 类型：

  • byte：uint8 的别名，代表 ASCII 字符（单字节）
  • rune：int32 的别名，代表 Unicode / UTF-8 字符（可以存中文、emoji）

byte：

  • 占用：1 字节
  • 范围：0~255，只适合英文字母、数字、英文符号（ASCII）
  • 字符串底层就是 []byte

rune：

  • 占用：4 字节
  • 存储一个完整 Unicode 码点，支持中文、日文、emoji、各国文字

字符串

基础特性：

  • string 底层是只读字节切片 []byte，本质存储 UTF-8 字节序列
  • 不可变：不能通过 s[i] = 'x' 修改字符串内字符
  • 字面量：双引号 "hello"；反引号 `原始字符串` 🧐

关于 len 函数：

Go 语言中 len 函数用在字符串时，用来获取字符串的字节数。
